# docs (GitHub Pages)

Source of the GitHub Pages site that publishes the infographics. Plain static
HTML/CSS/JS (no build step).

- `index.html` / `styles.css` — the landing page.
- `w-letter-map/` — an interactive infographic (map image plus `script.js`).

Each infographic lives in its own subfolder; add a new one by creating a folder
with its own `index.html` and linking it from the landing page.
